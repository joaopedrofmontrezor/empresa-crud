# Calculadora de Tabuada 🧮

Este é um projeto simples desenvolvido para praticar **HTML5**, **CSS3** e **PHP**. A aplicação permite que o utilizador insira um número num formulário elegante e visualize instantaneamente a respetiva tabuada de 1 a 10.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura do formulário de entrada.
- **CSS3:** Estilização moderna e centralizada (efeito "card" e transições).
- **PHP:** Processamento dos dados enviados via POST e cálculo dinâmico.
- **XAMPP / Apache:** Servidor local para execução do código PHP.

## 📁 Estrutura do Projeto

O projeto é composto por três ficheiros principais na pasta raiz:

- `index.html`: Página inicial que contém o formulário (campos de número, botão "Calcular" e botão "Limpar").
- `style.css`: Folha de estilos para deixar a interface visualmente agradável.
- `tabuada.php`: Script PHP responsável por receber o número, calcular a tabuada com um ciclo `for` e disponibilizar um botão para voltar.

## 🚀 Como Executar o Projeto Localmente

1. Certifica-te de que tens o **XAMPP** instalado no teu computador.
2. Inicia o serviço do **Apache** no painel de controlo do XAMPP.
3. Coloca os ficheiros (`index.html`, `style.css` e `tabuada.php`) dentro de uma pasta no diretório do servidor local:
   - No Windows: `C:/xampp/htdocs/tabuada/`
4. Abre o teu browser (navegador) e acede ao endereço:
   ```text
   http://localhost/tabuada/index.html
   ```
